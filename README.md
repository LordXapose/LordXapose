## About

I am a Berlin-based developer working across cybersecurity, software engineering, and financial
technology. I build practical tools for attack-surface research, threat analysis, endpoint
monitoring, and data-driven workflows.

My focus is on understanding how systems behave, turning that understanding into useful software,
and building with defensive and authorized use in mind.
