## Profile

I am a Berlin-based developer working across cybersecurity, software engineering, and financial
technology. I build practical tools for attack-surface research, threat analysis, endpoint
monitoring, and data-driven workflows.

I am interested in how systems behave under real conditions: how assets connect, how threats can
be identified, and how useful software can make complex information easier to understand.

clear analysis. I am interested in building software where those areas intersect: monitoring
systems, investigating events, and presenting complex information in a useful way.
